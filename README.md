# 📐 FS-7-Trigonometric-Calculator

his project is a menu-driven Trigonometric Calculator built using Python. It allows users to calculate trigonometric values such as sin, cos, tan, cot, sec, and cosec by entering angles in degrees.

The program uses Python’s built-in math library to perform accurate calculations by converting degrees into radians. Separate functions are created for each trigonometric operation, making the code easy to understand and maintain.

A while loop keeps the program running until the user chooses to exit, and if-else conditions handle user input and invalid cases like division by zero.

**🚀 Features**

1.Calculate Sin, Cos, Tan, Cot, Sec, Cosec

2.Degree to radian conversion using math.radians()

3.Menu-driven user interface

4.Handles invalid inputs (e.g., tan 90°, cosec 0°)

5.Beginner-friendly Python project

**🛠️ Technologies Used **
1.Python 
2.Math Library

🎯 Learning Outcome

1.Understanding Python functions

2.Using loops and conditional statements

3.Working with the math library

4.Handling mathematical edge cases
